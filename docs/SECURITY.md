# Security Policy

The opportunity to investigate and develop fixes before public disclosure is appreciated. Details will not published in a public Issue or Pull Request until a fix is available.
This project follows a 90 day disclosure timeline.

## Reporting a Vulnerability

Security is very important to this project. If you have any issue regarding security, please disclose the information responsibly by following these steps: 

- **Please, Do NOT create a public issue or pull request.**
- Please email security@voidwarex.com with the [Required Information](required-information).
- Alternatively, use GitHub's private vulnerability reporting feature.

### Required Information
To best assess the issue, please provide:
- A detailed description of the issue.
- Known affected versions.
- Steps to reproduce the vulnerability Forks or code samples are ideal.
- Solutions, Mitigations or Work Arounds for the issue, if any are known.

### Response Time
As a single-maintainer project, receipt acknowledgement will occur within 1 week and work to address the issue will begin as soon as possible.
